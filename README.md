# ⚡ Smart Electricity Management at Home Using IoT

## 📖 Overview

This project presents a **Smart Electricity Management System** using **IoT** to monitor household electricity consumption in real time. The system uses an **ESP32 microcontroller** along with **ACS712 Current Sensor** and **ZMPT101B Voltage Sensor** to measure energy usage and display live updates on an LCD. When electricity consumption approaches a predefined threshold (**200–210 units out of 250 units**), the system generates alerts to help users reduce unnecessary power usage.

The project aims to improve energy efficiency, reduce electricity bills, and promote smart home energy management.

---

## ✨ Features

- ⚡ Real-time electricity monitoring
- 📡 ESP32-based IoT system
- 🔌 ACS712 Current Sensor for current measurement
- 📈 ZMPT101B Voltage Sensor for voltage measurement
- 🖥️ LCD display for live energy usage
- 🚨 Threshold-based alerts (200–210 units)
- 🏠 Smart household energy management

## 🔄 Project Workflow

1. 📊 Sensors measure voltage and current.
2. 🧠 ESP32 processes the collected data.
3. ⚡ Electricity consumption is calculated continuously.
4. 🖥️ Live readings are displayed on the LCD.
5. 📱 Alerts are generated when usage approaches the predefined limit.
